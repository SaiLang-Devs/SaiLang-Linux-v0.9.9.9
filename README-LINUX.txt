SaiLang 0.9.9 for Linux (64-bit)
================================

This folder contains one program, "sai". It does not need Python installed.

1. Make it runnable (once):   chmod +x sai
2. Run a program:             ./sai myprogram.sai
3. Open SaiLang IDLE (the editor and runner; needs a desktop session):
                              ./sai idle
                              ./sai idle myprogram.sai

Other commands: ./sai check file.sai (look for mistakes), ./sai (interactive prompt).
Note: this is the original 0.9.9 release; its built-in version text reads "1.0.0".
